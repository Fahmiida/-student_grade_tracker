# Student Grade Tracker

A Flutter application for students to track their grades across different subjects.

## Features

- Add subjects with marks (0-100)
- View all subjects with marks and grades
- Swipe to delete subjects
- Summary dashboard with total subjects, average mark, and overall grade
- Dark/Light theme support

## Grade System

- A: ≥80
- B: ≥65  
- C: ≥50
- F: <50
